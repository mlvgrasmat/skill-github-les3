## Over deze opdracht

- Les: Remote Repository.

## Gebruikte Git-commando's
- `git clone`: maakt een lokale kopie van een repository op GitHub.
- `git status`: laat zien welke bestanden zijn gewijzigd.
- `git add README.md`: zet de README klaar voor een commit.
- `git commit`: slaat de klaargezette wijziging op in de lokale geschiedenis.
- `git push`: stuurt lokale commits naar GitHub.
